# Environmental

Monitor temperature, humidity, air quality, and compliance across facility zones.

## What it does

- Groups sensors into facility **zones** and shows current conditions per zone.
- Tracks temperature, humidity, and air-quality readings over time.
- Flags out-of-range conditions so you can act before a compliance excursion.

## Requirements

- Atrium platform **2.0.0** or newer.
- One or more environmental sensors reporting to the gateway.

## Permissions

- `data:read` — reads telemetry from the platform database (read-only).
