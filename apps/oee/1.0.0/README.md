# OEE

Overall Equipment Effectiveness tracking and analysis.

## What it does

- Calculates OEE from **availability**, **performance**, and **quality**.
- Trends OEE over time so you can measure the impact of process changes.

## Requirements

- Atrium platform **2.0.0** or newer.
- The **Productivity Monitor** app (OEE derives availability and performance
  from its runtime data).

## Permissions

- `data:read` — reads telemetry from the platform database (read-only).
